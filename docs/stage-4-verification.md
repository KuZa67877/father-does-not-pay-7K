# Проверка этапа 4 — интерактив

## Объём

Завершён пользовательский интерактив «Хроники» и «Ольхи». Новых зависимостей нет. Данные и мутации идут через существующий DI и репозитории; для просмотра «Актуального» добавлен `StoryRepository.get` (`GET /stories/:id`). Редактор статей и описание API остаются этапом 5; обзор, люди и статистика — этапом 6. Мессенджер остаётся предусмотренной заданием заглушкой, включая хранение ответов на истории.

## Автоматические проверки

Все перечисленные проверки проходят; Vitest: **105 тестов в 15 файлах**.

- `pnpm check`: TypeScript, ESLint без предупреждений, Vitest.
- `pnpm build`: production-сборки обоих приложений.
- `pnpm format:check`: форматирование репозитория.
- `git diff --check`: пробелы и конфликты в изменениях.

Тесты проверяют реальные REST-репозитории с MSW для реакций, комментариев, текстовых историй, просмотра, лайков, ответов, уведомлений и подписок. Компонентный тест фото проверяет выбор файла, вызов MediaRepository, передачу ID в публикацию и освобождение превью с подменой загрузки; multipart-загрузка и создание фотоистории дополнительно проверяются контрактным тестом. Таймер проверяется управляемыми часами, озвучка — подменой Web Speech API с проверкой отмены и подсветки.

В jsdom используются нативные AbortController/AbortSignal Node: Node 24 отклоняет сигналы jsdom в нативном fetch. Настройка общая для обоих приложений в `packages/config/test-fetch.ts`.

У историй используются более тёмные фоны из палитры проекта для читаемости белого текста. Полный аудит доступности и Lighthouse остаются этапом 6.

Chrome MCP показывает скриншоты в ответах инструмента, но отклоняет сохранение файлов в проект и выбор локального файла: его workspace roots не настроены. Поэтому новые итоговые скриншоты на диск не сохранены. Для браузерной проверки загрузки использовано собственное тестовое изображение, созданное в памяти, без чтения локальных файлов или скачивания ресурсов. Python Playwright не установлен; дополнительные пакеты не устанавливались.

## Что посмотреть вручную

1. В «Хронике» открыть материал: выбрать, переключить и снять реакцию; написать комментарий и ответить на него; запустить озвучку и перейти на другую страницу.
2. В «Ольхе» нажать «История», опубликовать текст или фото; открыть «Ваши истории», проверить паузу, стрелки, свайп и список зрителей.
3. На чужой истории поставить лайк и отправить ответ. Ссылка «Сообщения» ведёт на предусмотренную ТЗ заглушку.
4. Открыть `/notifications`, переключить фильтры, прочитать одно уведомление и все сразу; проверить счётчик в меню.
5. Найти автора через поиск, подписаться и убедиться, что кнопка сразу обновилась; проверить то же состояние в профиле.

Моки хранят изменения в памяти вкладки; перезагрузка и полное обновление модулей dev-сервера сбрасывают демонстрационные данные.

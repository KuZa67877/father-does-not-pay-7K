# Дизайн-токены

Источник — живые демо (`demo-time.dlemod.com`, `demo-velora.dlemod.com`, сняты 12.10.2026 через вычисленные стили, `getComputedStyle` + CSS custom properties в `:root`) и 62 скриншота из `dlemod.com/storage/modules/*` (лежат локально в `docs/reference/`, в git не попадают).

Обозначения: **[демо]** — значение снято с живой страницы; **[скрин]** — измерено по скриншоту 1600×1000; **[решение]** — значение выбрано нами, потому что на референсе его не видно.

CSS-код и картинки оригинала не копировались — только числовые значения (цвета, размеры, радиусы), шрифты — открытые (OFL, Fontsource).

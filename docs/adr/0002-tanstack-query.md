# ADR-0002. TanStack Query для серверного состояния

**Статус:** принято · 2026-10-12

## Контекст
Нужны кеш, «Показать ещё», бесконечная лента с курсором, оптимистичные лайки/реакции/подписки и единые состояния загрузки/ошибки.

## Решение
TanStack Query v5. Ключи запросов собраны в `shared/api/query-keys.ts`; `queryFn` вызывает только репозитории из DI, передавая `signal` для отмены.

## Последствия
- Глобальный стор (Redux/Zustand) не нужен: серверные данные — в Query, клиентские — в компонентах и URL.
- Повторы делает HTTP-клиент (только идемпотентные), Query повторяет лишь сетевые сбои — чтобы не умножать попытки.

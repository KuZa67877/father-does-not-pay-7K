# ADR-0001. React 19 + Vite + TypeScript strict

**Статус:** принято · 2026-10-12

## Контекст
Два приложения с богатым интерактивом (слайдер, истории, плеер, редактор), требование «без UI-китов» и строгая типизация.

## Решение
React 19 + Vite 7 + TypeScript (`strict`, `noUncheckedIndexedAccess`, запрет `any`). React Router 7 в режиме data router с `lazy` для разбиения по страницам.

## Последствия
- Большая экосистема (TanStack Query, RHF, Testing Library) без привязки к метафреймворку.
- SSR не нужен для учебной задачи; SEO закрываем мета-тегами и семантикой. Если понадобится SSR, React Router 7 позволяет перейти в framework mode без переписывания страниц.

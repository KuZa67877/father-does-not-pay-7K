# ADR-0003. Репозитории (порты) + DI через React Context

**Статус:** принято · 2026-10-12

## Контекст

Бекенд неизвестен: свой REST, Strapi, Directus или WordPress. Смена источника не должна трогать UI.

## Решение

- В `@dle/core` — интерфейсы репозиториев и Zod-схемы доменных моделей; без React.
- В `@dle/data` — адаптеры: REST по `openapi.yaml`, MSW-мок, CMS-адаптеры с мапперами DTO → домен.
- Приложение при старте собирает объект репозиториев (`data-source.ts`) и кладёт его в `RepositoriesContext`; дальше — только `useRepositories()`.
- Импорт `@dle/data` вне `src/app/**` запрещён правилом ESLint.

## Последствия

- Подмена в тестах — один провайдер с фейками.
- Цена — немного шаблонного кода на каждый метод. Принимаем ради независимости UI от бекенда.

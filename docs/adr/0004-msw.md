# ADR-0004. MSW вместо in-memory-репозиториев для mock-режима

**Статус:** принято · 2026-10-12

## Контекст
Приложение должно полностью работать без бекенда, включая создание статей и загрузку файлов.

## Решение
Mock-режим = тот же REST-адаптер + Mock Service Worker, который перехватывает `fetch`/XHR и отвечает из фикстур (`@faker-js/faker` с фиксированным seed + написанные вручную тексты). Состояние мока — в памяти вкладки; файлы — `URL.createObjectURL`.

## Последствия
- Mock проходит путь боевого клиента: URL, заголовки, `multipart/form-data`, коды ошибок, Zod-валидация. Обработчики MSW одновременно служат исполняемой спецификацией API.
- Те же обработчики используются в контрактных тестах через `msw/node`.
- Состояние сбрасывается при перезагрузке — осознанно, для предсказуемых демо. Перенос в IndexedDB — при необходимости на этапе 5.

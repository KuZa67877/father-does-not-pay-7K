# Контракт API

Полная спецификация OpenAPI 3.1 — [`../openapi.yaml`](../openapi.yaml). Time и Velora обслуживаются независимыми API: пути общего слоя совпадают, данные и сессии разделены. `VITE_API_URL` включает префикс API (например, `https://example.com/api`).

## Источник контракта и типы

`packages/data/src/contract/openapi.ts` описывает операции, параметры и коды ответов. Схемы берутся из Zod в `packages/core`, включая пять форматов статьи, восемь типов блоков и рекурсивные комментарии. `openapi.yaml` генерируется в JSON-нотации YAML 1.2; вручную его менять не нужно.

```bash
pnpm api:generate # обновить спецификацию и api.gen.ts через openapi-typescript
pnpm api:check    # проверить отсутствие расхождений
```

Генерация спецификации использует существующий TS-конвейер Vitest. Обычный тест только сравнивает файл с актуальной схемой; запись включается исключительно `UPDATE_API=1`. Типы находятся в `packages/data/src/generated/api.gen.ts`, используются в REST-запросах создания/изменения статей и постов, отправки читательских материалов. Ответы дополнительно проверяются Zod во время выполнения.

## Операции

| Группа                        | Пути                                                                                                                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Общие                         | `/auth/me`, `/auth/login`, `/auth/register`, `/auth/logout`, `/auth/password-reset`, `/media`, `/media/{id}`                                                                                           |
| Time: материалы               | `/articles`, `/articles/trending`, `/articles/{key}`, `/articles/{id}/related`, `/articles/{id}/favorite`, `/articles/{id}/reaction`, `/articles/{id}/comments`                                        |
| Time: справочники и подписки  | `/rubrics`, `/rubrics/{key}`, `/rubrics/{id}/stats`, `/rubrics/{id}/authors`, `/rubrics/{id}/subscription`, `/me/subscriptions`, `/tags/{slug}`, `/topics`, `/newsletter`                              |
| Time: редакция и сводка       | `/submissions`, `/widgets/weather`, `/widgets/currency`, `/widgets/city`                                                                                                                               |
| Velora: контент               | `/feed`, `/posts`, `/posts/{id}`, действия `/like`, `/save`, `/pin`, `/report`, `/vote`, `/comments`                                                                                                   |
| Velora: истории               | `/stories`, `/stories/{id}`, действия `/view`, `/like`, `/reply`, `/viewers`, `/users/{login}/highlights`                                                                                              |
| Velora: люди                  | `/users`, `/users/suggestions`, `/users/top`, `/users/{login}`, действия `/follow`, `/notify`, `/followers`, `/following`, `/me/profile`                                                               |
| Velora: остальное             | `/categories`, `/categories/{slug}`, `/categories/{id}/subscription`, `/categories/{id}/notify`, `/tags/trending`, `/notifications`, `/notifications/unread-count`, `/notifications/read`, `/me/stats` |
| Общий путь, разные результаты | `PUT /comments/{id}/like`: Time — `204`, Velora — `200 LikeState`                                                                                                                                      |

Создание статьи/поста/истории/комментария/медиа/сессии регистрации и читательского материала возвращает `201`. Остальные операции с результатом — `200`; операции без результата — `204` без JSON-тела. `GET /auth/me` для гостя возвращает `200 null`. Все изменяющие запросы используют JSON, кроме загрузки медиа.

`GET /articles/{key}` принимает slug; `PATCH` и `DELETE` на том же шаблоне принимают **id**. Вложения передаются как ID ранее загруженных медиа; блоки и поля форматов статьи содержат доменные объекты `Media`. Сервер обязан проверять существование и доступность всех ссылок. `PATCH` сливается с текущими данными, после чего валидируется полный объект.

## Пагинация и фильтры

Time: `page` (от 1), `pageSize` (до 50); ответ `{items,total,page,pageSize}`. Фильтры: `rubric`, `tag`, `author`, повторяемый `format`, `readingTime=all|short|long`, `search`, `sort=new|popular|discussed`, `status=draft|published|all`, `featured`, `breaking`, `mine`, `favorites`, `subscribed`, `since`. По умолчанию выдаются опубликованные материалы. Короткое чтение — до пяти минут включительно.

Velora: непрозрачный `cursor` и `limit`, ответ `{items,total,nextCursor}`; `null` означает конец выдачи. Для ленты — `kind=all|following|circles`, категория. Для постов — автор, категория, тег, поиск, вкладка профиля, сортировка и период. Для людей — поиск и курсор. Полный список параметров указан у операций в спецификации.

Массивы query-параметров передаются повторением ключа: `format=video&format=photoReport`. Булевы значения — `true`/`false`. Даты — ISO 8601 с часовым поясом. Времена аудиотаймкодов и длительности — в секундах; размер файла — в байтах; прогресс загрузки на фронтенде — от 0 до 1.

## Авторизация и бизнес-правила

Пользовательский токен передаётся `Authorization: Bearer <token>` и хранится через `TokenStore`. Проверка прав выполняется сервером на каждом запросе. Автор или администратор может изменять и удалять материал; чужой черновик скрывается из списков и возвращает `404` при прямом обращении. `mine` требует входа. Счётчики, автор, slug и время публикации назначаются сервером. Slug при изменении заголовка сохраняется.

Для реакций передаётся выбранный тип или `null`; для переключателей — `{value:boolean}`. Голосование проверяет варианты и возможность повторного выбора. Истории доступны с учётом срока, аудитории и сохранения в «Актуальном»; зрители — только автору. `notifications/read` принимает `{ids:[...]}` либо `{ids:"all"}` и изменяет только уведомления текущего пользователя.

Отправка в редакцию доступна читателю с файлом и `consent:true`, именем и контактом. В JSON Schema не выражены все Zod-refinement и серверные ограничения: непустой пост, принадлежность подрубрики, права на медиа и публикацию проверяются дополнительно. Моки учебные и хранят состояние в памяти вкладки, до перезагрузки.

## Загрузка и ошибки

`POST /media`: `multipart/form-data`, поле `file`, необязательное `type=image|video|audio|file`. До 20 МБ на файл. Возвращает `Media`; `DELETE /media/{id}` удаляет медиа с проверкой прав и используемых ссылок на настоящем сервере. Для читательских материалов сервер может разрешать ограниченную гостевую загрузку. Клиент не выставляет multipart boundary вручную, показывает прогресс XHR, отменяет запрос при удалении/закрытии, позволяет повторить отказ. Загрузки не повторяются автоматически.

```json
{ "error": { "code": "validation", "message": "Проверьте поля статьи", "details": [] } }
```

| HTTP      | `error.code`                       |
| --------- | ---------------------------------- |
| 400       | `bad_request`                      |
| 401 / 403 | `unauthorized` / `forbidden`       |
| 404 / 409 | `not_found` / `conflict`           |
| 413 / 422 | `payload_too_large` / `validation` |
| 429 / 5xx | `rate_limited` / `server`          |

Локальные ошибки клиента: `network`, `timeout`, `aborted`, `invalid_response`. Таймаут по умолчанию — 15 секунд. Повторы только для GET/PUT/DELETE при сетевых ошибках, таймауте и 5xx, до двух раз; 429 автоматически не повторяется. Для Strapi используется отдельный транспортный DTO и маппер, см. [настройку CMS](strapi.md).

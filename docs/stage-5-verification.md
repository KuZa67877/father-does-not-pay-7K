# Проверка этапа 5

Дата: 19 октября 2026. Проверки выполнялись локально, без установки дополнительных UI-библиотек. С разрешения пользователя добавлена только dev-зависимость `openapi-typescript` с транзитивными пакетами.

## Реализовано

- `/editor`, `/editor/new`, `/editor/:slug`: свои материалы, фильтр статуса и пагинация, создание/редактирование, черновик/публикация, подтверждение удаления, загрузочные/пустые/ошибочные состояния и проверка сессии/автора.
- Пять форматов и восемь типов блоков, перестановка и удаление блоков, факты, таймкоды; обложка, фото и аудио загружаются через MediaRepository.
- Отправка читательских фото/видео под статьёй, контакт и обязательное согласие на публикацию.
- Общая очередь загрузок для двух приложений: прогресс, отмена, повтор, порядок, лимиты и освобождение превью. Учтена замена файла в одном событии и несколько добавлений до React-render.
- Пример Strapi 5 с DTO-маппингом, CRUD статей, фильтрами, рубриками, Upload plugin и прикладными REST-портами. OpenAPI всех портов и генерация TypeScript-типов; проверка актуальности контрактов.
- Мок скрывает чужие черновики, проверяет обложку, связь подрубрики и медиа читательского материала. HTTP учитывает уже отменённые сигналы, таймаут multipart и очистку слушателей.

## Автоматические проверки

`pnpm check`: TypeScript всех пакетов, ESLint без предупреждений, **132 теста в 20 файлах**. Общий набор TimeRepositories выполняется для REST + MSW и Strapi 5 + прикладного REST-стенда. Дополнительно проверены URL/id/размеры Upload DTO и отклонение некорректного ответа CMS.

Компонентные проверки редактора: обязательные поля, черновик с тегами, публикация четырёх специальных форматов, фото/аудио через порт загрузки, таймкод, перестановка вложенных фактов и сохранение ввода при отказе сервера. Проверки очереди: пакетный лимит, замена, abort, retry, порядок и revokeObjectURL. Читательская форма не отправляется без согласия. Существующие тесты «Нового поста» и историй проходят после переноса очереди.

`pnpm api:check`, `pnpm build`, `pnpm format:check`, `git diff --check` проходят. Rollup сообщает о расположении PURE-комментариев внутри установленного Zod; сборки успешны, сторонние исходники не менялись.

## Браузер

В Chrome проверены выбор рубрики, теги, загрузка созданного в памяти PNG через настоящий multipart/XHR, сохранение черновика с переходом к редактированию, публикация, список своих статей и удаление с подтверждением. После удаления API возвращает пустой список собственных материалов. Перезагрузка вкладки сбрасывает учебную базу — это ограничение mock, описанное в README.

Редактор просмотрен на 375, 768 и 1440 px в светлой и тёмной теме; горизонтального переполнения нет. На телефоне поля рубрик и кнопки переносятся, панель сохранения не фиксируется поверх формы. Редактор следует существующим токенам «Хроники»: антиквенные заголовки, линейки, спокойные поля, оранжевое основное действие. Отдельного референса редактора в предоставленной подборке нет; набор и композиция полей основаны на ТЗ. Читательская форма ориентируется на сохранённый `time-22-upload.webp`.

Скриншоты просмотрены в ответах Chrome MCP. Сохранение файлов и выбор файлов с диска недоступны из-за workspace roots этого инструмента (ограничение зафиксировано на этапе 4); ограничение не обходилось. Реальный сервер Strapi не запускался: пример проверен транспортным стендом, необходимые серверные контроллеры и политики явно перечислены в `docs/strapi.md`.

## Проверка границ кода

SOLID/DRY/KISS/YAGNI проверены перед реализацией и по итоговому изменению. Форма, поля формата, блочное тело, мутации и транспорт разделены по текущим обязанностям. Очередь загрузки, MIME-маппинг, порог короткого чтения и пустой ответ переиспользованы. UI зависит от портов; DTO остаются в data. Новые зависимости для редактора и гипотетические CMS-возможности не добавлены. Существующие Blender/STL и локальная `.claude/` не изменялись и не включались в коммит.
